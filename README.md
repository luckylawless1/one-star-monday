A one-star review of Monday, written as if Monday were a restaurant.

`main.ts` (Node 22, stdlib only) writes a single line to `/output/entry.txt`:

> Waited an hour for a table, then the waiter served me a whole week. Monday's kitchen should stay closed forever.

Run it with:

```sh
node main.ts
```
